# Retired experiment drivers

The shared native agent/general-memory migration removes old local-model, JSON planner,
statement-writer, departure and second-judge implementations. Drivers depending on those retired
interfaces were removed rather than retaining alternate product implementations. Historical
source remains in Git at `fddd1f3` (and its parents); frozen JSON datasets and research findings
remain. Old results describe the old prompts/models, not current acceptance.

Current entry points: `household_workflows.py`, `recall_workflows.py`, `planner.py` (native calls),
`visual_verification_replay.py`, `physical_scene_replay.py` and `local_replay_audit.py`.
Shared paid guards live in `budget.py`; cloud tests use only public/synthetic fixtures. Private
library audits use copied indexes and local decoding without provider inference.

helpers live in `native_voice.py`; actual automatic-memory workflows use `household_spoken_replay.py`.
