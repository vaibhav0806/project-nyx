at bdb7ad0. Continue inline on work/memory-reliability, fast-forwarded to that merge; never edit
main or contributor UI. Local recordings stay offline; cloud tests use public/synthetic evidence
only under the existing $5 TOTAL cap. No hardware, private uploads, automatic expiry or new account.

Evaluate actual API planning, decoded visual windows, reference resolution, embeddings, durable
report storage, restart/context eviction and source-attributed recall together. Use existing
compatible vectors/models. Eight frozen source-separated workflows (four development/four
holdout) cover a shown object that disappears before the utterance ends, later recall, normal
moves, corrections, intentions and simultaneous ambiguous objects. Labels concern report/source
attribution and appropriate uncertainty; user statements do not prove physical placement.

Public-image crops/composite edited videos provide exact demonstrated-object provenance but
are explicitly synthetic visual conditions, not natural household-video acceptance. Reuse
existing public household clips for an additional natural-video diagnostic if their provenance
and labels support it. Past private clips may support offline integrity/timestamp checks only.

Freeze source hashes/splits/expected report IDs before paid inference. Capture every stage and
failed/not-run case, plus independent evidence/intent outcomes; don't inflate aggregate scores
with easy negatives or infer correctness from tool shape. Keep free-form answer audit separate.
No forced initial planner actions. Retain original failed runs; any fixes use general invariants
with failing regressions. Do not tune on detailed heldout outputs or add object/fixture rules.

Promote only measured general backend repairs, preserve baseline model choices unless fresh
comparisons justify a change, and finish with full checks and branch-only commits/backup.
Household acoustics, real-person placement/identity and long-run deployment remain separate gates.
